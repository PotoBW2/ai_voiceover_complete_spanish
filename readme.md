# VoiceOver para World of Warcraft

## v2: https://allvoice.ai

Contribuye con voces en [allvoice.ai](https://allvoice.ai) para que cada PNJ tenga un modelo de voz de IA único que impulse sus diálogos. Se usará la voz mejor valorada de cada PNJ.

### [voiceover discord](https://discord.gg/VdhUmA8ZCt)
### [código de allvoice](https://github.com/allvoice/allvoice-website)

## Descripción general
- tts cli para crear archivos de audio para misiones y textos de diálogos.
- Complemento del juego para reproducir voces en off generadas

- cli utiliza datos obtenidos de una base de datos MySQL local y ElevenLabs tts para voz

## Instalación del complemento
Copia la carpeta `generated` a la carpeta VoiceOverData_Vanilla, y luego las carpetas VoiceOver y VoiceOverData_Vanilla a `World of Warcraft/_classic_era_/Interface/AddOns`.
